# Standalone SDK elements

After `npm run build`, serve the repository root and open `http://localhost:8000/examples/elements-standalone/`. This minimal application connects the SDK builder, rate selector and purchase confirmation elements. It requests a sandbox Base64 credential at runtime and never stores it.

For the complete storefront, open https://a-i-e-s.github.io/javascript-sdk/. For host-controlled manual packaging, open https://a-i-e-s.github.io/javascript-sdk/manual.html.
