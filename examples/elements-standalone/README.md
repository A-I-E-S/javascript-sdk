# Standalone SDK elements

After `npm run build`, serve the repository root and open `http://localhost:8000/examples/elements-standalone/`. This minimal application connects the SDK builder, rate selector and purchase confirmation elements. It defaults to a local no-network fixture transport. Real sandbox calls and runtime Base64 credential entry are explicitly opt-in; credentials are never stored.

For the complete storefront, open https://a-i-e-s.github.io/javascript-sdk/. For host-controlled manual packaging, open https://a-i-e-s.github.io/javascript-sdk/manual.html.
